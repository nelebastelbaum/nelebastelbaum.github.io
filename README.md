# Neles Bastelbaum – Website

Öffentliche Seite von Neles Bastelbaum, ausgeliefert über GitHub Pages: https://nelebastelbaum.github.io/

- `index.html` – Startseite
- `stundenplan/` – Neles Stundenplan (läuft komplett im Browser, Daten nur im localStorage des Geräts)
- `media/` – öffentliche Bilder für Social-Media-Posts (Metricool holt sie über die öffentlichen Links)
- `impressum.html`, `datenschutz.html`

**Wichtig:** Dieses Repository ist öffentlich. Hier kommen nur Dinge hinein, die ohnehin öffentlich sind. Bezahlte Vorlagen (PDFs) gehören nie hierher.
